VERSA — English learning website

Static website with a light orange theme, optional dark mode, fourteen English lessons (including action verbs, verb tenses, irregular verbs, modal verbs, and subject–verb agreement), interactive quizzes with answer explanations, speech playback, and optional browser speech recognition. No account or backend is included. Quiz history is kept in the current browser tab only.

To deploy on Vercel: extract this ZIP, put the folder in a Git repository and import it in Vercel, or use the Vercel CLI from this folder. Select the Other framework preset; no build command is needed, and the output folder is the folder containing index.html.
